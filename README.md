# Walmart Store Sales Prediction 🛒💰

## Overview

Welcome to the **Walmart Store Sales Prediction** project! This project aims to predict weekly sales of Walmart stores using various machine learning models. By analyzing a comprehensive dataset covering store information, sales, and economic factors, we build and evaluate models to forecast store sales and support data-driven decision making.

---

## Dataset Description

The dataset includes the following key columns:

| Column           | Description                                              |
| ---------------- | -------------------------------------------------------- |
| **Store**        | Unique identifier for each Walmart store.                |
| **Date**         | Date when the sales were recorded.                       |
| **Year**         | Year of the recorded sales data.                         |
| **WeeklySales**  | Total sales for the week (target variable).              |
| **HolidayFlag**  | Indicates if the week includes a holiday (1) or not (0). |
| **Temperature**  | Regional temperature during the week.                    |
| **Fuel_Price**   | Fuel price in the region during the week.                |
| **CPI**          | Consumer Price Index reflecting cost of living changes.  |
| **Unemployment** | Regional unemployment rate during the week.              |

---

## Key Objectives

* **Exploratory Data Analysis (EDA):** Investigate sales trends, patterns, and feature correlations.
* **Model Building:** Develop and compare machine learning models for sales prediction, including:

  * XGBoost
  * Logistic Regression
  * Support Vector Machine (SVM)
  * Random Forest
  * Decision Tree
* **Model Evaluation:** Assess model performance using accuracy and F1 score metrics.
* **Prediction:** Forecast future weekly sales using the best-performing model.

---

## Models Implemented

* **XGBoost:** Efficient and powerful gradient boosting algorithm.
* **Logistic Regression:** Linear model for classification tasks.
* **Support Vector Machine (SVM):** Versatile algorithm for classification and regression.
* **Random Forest:** Ensemble method combining multiple decision trees.
* **Decision Tree:** Simple, interpretable model based on feature splits.

---

## Evaluation Metrics

* **Accuracy:** Percentage of correctly predicted instances.
* **F1 Score:** Harmonic mean of precision and recall, balancing false positives and negatives.

---

## Results & Predictions

Using the top-performing model, we generated predictions to forecast Walmart store sales, enabling better inventory and operational planning.
